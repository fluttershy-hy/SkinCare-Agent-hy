# 脂溢性皮炎／马拉色菌文献发现

本项目使用 `scripts/discover-literature.sh` 从 Europe PMC 的公开检索接口批量收集候选文献的题目、作者、期刊、年份、DOI/PMID 和检索词。脚本不抓全文，也不自动将摘要或标题写成风险规则。运行：

```bash
bash scripts/discover-literature.sh /tmp/skincare-literature-candidates.json
```

截至 2026-11-01，云环境对 `www.ebi.ac.uk` 和 `eutils.ncbi.nlm.nih.gov` 的请求在代理 CONNECT 阶段返回 403；已保存网络配置草稿，待发布后才能实测检索。离线夹具已验证脚本的请求循环、元数据去重和输出格式。此次尚未核实任何具体研究，也未改变成分风险规则。

后续审读每篇候选时记录：研究对象是菌株培养、体外皮肤模型、动物还是真实患者；研究的脂肪酸是游离成分还是成品配方；浓度、剂量、使用部位与暴露时间；研究是否测量皮炎症状；结果是否可跨菌种/部位/产品版本外推。只把能支撑的窄结论连同 DOI、原文段落和局限写入知识条目。尤其不会将“可被马拉色菌利用”直接转换成“含该成分的产品一定诱发脂溢性皮炎”。
