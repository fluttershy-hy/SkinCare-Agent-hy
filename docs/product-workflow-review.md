# 产品解读工作流与资料核查（2026-11-01）

用户提供的 `SkinCare-Knowledge.doc` 是需求草稿和候选资料清单，不是已核实的成分或医学来源。本次先把可由现有代码可靠实现的流程落地：在同一聊天窗口填写具体产品全名、可选的完整成分表、使用部位、当前状态、自述敏感和已确认过敏成分。若只有产品名，调用现有 `ProductSearchService` 寻找配置过的品牌官网候选页；该服务不会提取完整 INCI，所以此时不评价适用性。用户粘贴成分表后，Java 保留原顺序并强制匹配已确认过敏成分，再检索来源并生成谨慎回答。未确认的“脂皮”或敏感描述不写入长期画像，也不等同诊断。

以下主张尚无可核对的原始资料、授权数据或确切产品配方，**没有进入确定性风险规则**：

- “适乐肤神经酰胺屏障修护润肤霜”与英文 `CeraVe Moisturizing Cream` 是同一具体版本，以及文档列出的完整 INCI。产品各市场或版本可能不同，需要包装全名、地区、批次或官方完整列表。
- 将 C11–C24 油脂或所有脂肪醇统一标为脂溢性皮炎高风险，进而断言面部不可用、身体适合用；以及“厚重霜体给马拉色菌提供温床”的个体结论。这些需要具体成分、配方和针对人群的证据，不能从名称或质地一跳推到个人结论。
- 用单成分致痘 0–5 分直接给整款产品或个人标注五级风险；“已确认过敏原匹配”与“法规禁限用”也不能合并成同一过滤规则。前者是个人已确认记录匹配，后者需要地区、用途、浓度和现行法规。
- 文档中列出的 Open Cosmetics MCP、INCI API、Dermalytics、CureSkin、INCILABS 等数据量、价格、许可、接口能力及质量。接入前需核对官方地址、API 文档、许可条款、样例响应与真实产品覆盖。

若要进一步实现自动 INCI 查询与病理风险标签，最有用的补充是：① 一款演示产品包装上的完整名称、销售地区和完整成分表，最好附品牌官网具体产品页；② 拟接入数据源的官方项目/API 文档和许可链接；③ 脂溢性皮炎及马拉色菌相关**原始研究或专业指南**中支持具体成分判断的章节。项目仅使用虚构用户，不需要真实病历。
